# Sources de référence fournies

`ML-RAG-master/` conserve les fichiers Python du ZIP reçu, avec leur contenu d'origine. Le pipeline applicatif utilise exclusivement `src/rag_fomc/`.

Les choix repris et leurs adaptations sont décrits dans `../docs/INTEGRATION_ML_RAG.md`. Ces sources de référence ne participent ni à l'import des paquets applicatifs, ni à la découverte des tests configurée pour ce projet. Les fichiers `.env`, bytecodes et réglages locaux du ZIP ne sont pas importés.
